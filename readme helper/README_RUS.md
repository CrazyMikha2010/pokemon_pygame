# Pokemon Pygame

<img src="readme helper/0056Mankey.webp" width="200"/>

[English README](../README.md)

Простая игра о покемонах на Python и Pygame. Лови, выбирай и сражайся покемонами с тренерами в графическом интерфейсе.

## Возможности
- Лови покемонов, кликая по миру
- Выбирай свою команду и сражайся против другого тренера
- Анимированная битва с полосками здоровья и пошаговыми атаками
- Перезапусти игру кнопкой после окончания битвы

## Требования
- Python 3.8+
- Pygame

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/yourusername/pokemon_pygame.git
   cd pokemon_pygame
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование
Запустите игру из директории `game`:
```bash
python main.py
```

## Управление
- **Клик мышью**: Поймать покемона или добавить нового
- **Кнопка перезапуска**: Появляется после окончания битвы, нажмите для перезапуска
- **Выход**: Закройте окно или нажмите кнопку закрытия

## Тестирование
У меня не возникло проблем при разработке игры

## ООП паттерны и методы, которые я использовал
- **facade**: Фасад Pygame с его основными командами
- **static methods**: функции, не требующие дополнительной информации внутри класса
- **property**: геттеры и сеттеры для свойств покемона
- **singleton**: гарантирует существование только одного экземпляра PygameFacade. Я реализовал это как декоратор

В целом я старался максимально оптимизировать код и разделить его на файлы
